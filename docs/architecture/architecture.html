Architecture

How the CRM is built

The technical companion to the product plan — Australian Payroll Association · payrollgroup.com.au

1 · Overview

This is a Next.js (App Router) app deployed on Vercel, backed by a Supabase Postgres database, with Resend for email. It has two surfaces: a public marketing site that captures leads, and an /admin CRM. /admin starts open and unprotected, and gets locked down with email-and-password Supabase Auth later in the build.

2 · How the pieces fit

Next.js (App Router)

Renders the public marketing site and the /admin CRM. Server code handles form submissions and all database reads and writes — the browser never talks to the database directly.

Vercel

Hosts and deploys the app. Environment variables hold every secret. A git push triggers a deploy — no manual deploys.

Supabase (Postgres)

The database. Accessed server-side only, using the service key. Secrets never reach the browser.

Resend

Sends the confirmation email when a lead comes in. Wired in Build 2, once the sending domain is verified.

Environment variables

VariableWhat it's for
NEXT_PUBLIC_SUPABASE_URLThe address of your Supabase project.
NEXT_PUBLIC_SUPABASE_ANON_KEYPublic key for any safe, client-side Supabase calls.
SUPABASE_SERVICE_ROLE_KEYSecret key for server-side reads/writes. Never exposed to the browser.
RESEND_API_KEYAuthenticates Resend to send the confirmation email.
NEXT_PUBLIC_SITE_URLYour live domain — used for email links and redirects.

3 · The lead flow

One inquiry, traced end to end:

  1. A visitor submits the contact form on payrollgroup.com.au.
  2. The server upserts a People row by email — a returning person is matched, never duplicated.
  3. The server creates a linked Contacts row in status new_lead.
  4. (Build 2) Resend sends the visitor a confirmation email from your domain.
  5. You see the lead in /admin, newest first, and work it through the pipeline.
  6. Each status change writes one activity_log row, so the history is permanent.

5 · Relationships

  • One Person has many Contacts (inquiries).
  • One Contacts row has many activity_log rows.
  • One Person has many Orders.
